## Key Features of Session

- **Private messenger as the client** – Session Private Messenger is identity, devices, and the inbox. Session Encrypted Chat lives here. Session Group Chat is a room in the same inbox. Session Account ID is the login. Session Onion Path is how it travels. Recovery stays offline.
- **Encrypted chat as 1:1** – Session Encrypted Chat is bilateral. Media stays in the thread. Session Private Messenger should not auto-add unknown IDs into work. Session Group Chat is the wrong place for a secret that is only for two people. Session Account ID still applies. Session Onion Path does not change the roster.
- **Group chat as a roster** – Session Group Chat needs an owner, a name, and an exit. Prefer several small rooms over one dump. Session Private Messenger will otherwise drown in noise. Session Encrypted Chat remains for 1:1. Session Account ID still belongs to people, not to the room title. Session Onion Path still does not replace membership you control.
- **Account ID as identity** – Session Account ID is an ID you control, not a phone number. Back up recovery offline. Session Private Messenger starts from that ID. Session Encrypted Chat and Session Group Chat inherit it. Session Onion Path does not hide a public paste of the ID. Do not put Session Account ID on a wiki.
- **Onion path as transport** – Session Onion Path is how packets move. Treat it as transport. Session Private Messenger still needs a roster. Session Encrypted Chat still needs a known party. Session Group Chat still needs an owner. Session Account ID still must stay private. This is not a scan of random nodes for a hobby.

## Quick Start with Session

1. **Create identity** – Open Session Private Messenger. Store Session Account ID and recovery offline. Do not create Session Group Chat yet. Send Session Encrypted Chat to a known contact. Ignore Session Onion Path except as the default route.
2. **Prove a thread** – Use Session Encrypted Chat as normal. Session Private Messenger is now an operational channel. Still no large Session Group Chat. Recheck that Session Account ID is not on a public page. Session Onion Path unchanged.
3. **Add a named group** – Create one Session Group Chat with people who already work together. Name it. Keep Session Encrypted Chat for 1:1. Session Private Messenger should show a short list. Session Account ID unchanged. Session Onion Path unchanged.
4. **Attachments on purpose** – Send a named file in Session Encrypted Chat or Session Group Chat only if needed. Session Private Messenger still owns the inbox. Session Account ID still private. Session Onion Path still transport. Do not treat every file as a reason to widen the roster.
5. **Review** – Leave Session Group Chat you do not operate. Unpin noise. Session Private Messenger should show a short list. Session Encrypted Chat stays the default. Recheck recovery for Session Account ID. Session Onion Path still not a public overlay hobby.
